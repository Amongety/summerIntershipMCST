Описание решения задачи:
Перебираю массив пока он возрастает, иначе если 
кол-во равно то смотрю на сумму или количество больше
тогда сохраняю это как максимум и где находится эта увеличивающаяся подпоследовательность.
После цикла обязательно смотрю не была ли полсденяя подпоследовательность больше сохраненной

Временная сложность: O(n)
Пространственная сложность: O(1)
