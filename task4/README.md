Описание решения задачи:
Программа опирается на заготовленные массивы с "опциями".
Чтобы решить проблему чтения длинных параметров ("--*") в getopt, я вручную двигаю индекс
элемента argv (optind), также имеется булевый массив, для того чтобы не учитывать одни и те же флаги
Улучшения:
Использовать getopt_long для длинных и коротких ("-*") параметров это помогает избегать двойное чтение и упрощает чтение кода
